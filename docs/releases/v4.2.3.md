# Konoha 4.2.3 — Product Finalization and Distribution Hermeticity

This is a patch and finalization release on top of v4.2.2. It introduces no
new product capability and changes no production behavior.

## Included

- REF-024 makes distribution tests independent from developer `HOME` and
  XDG configuration, using isolated synthetic environments.
- The stale public installable terminal distribution guide now uses the
  v4.2.3 install reference and version in its examples.
- Release and version metadata identify the 4.2.3 patch.

The Product Finalization Checkpoint completed with zero release blockers.
Remaining backlog is nonblocking and is not included in this release.

Konoha remains local-first and terminal-first. Explicit human approval remains
required for missions and consequential actions. No approval, execution,
provider, Git, or release authority changes are included.

## Validation

Release validation results are recorded in the associated final release
report. Creating a tag, pushing, updating `main`, and publishing a GitHub
Release remain separate maintainer-controlled actions.
