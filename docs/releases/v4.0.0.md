# Konoha 4.0.0 — Conversational Multi-Agent Operating Core

This is the published v4.0.0 release document. Git tag creation, push and
any GitHub Release are separate maintainer operations, tracked and performed
independently of this document; this document does not itself authorize or
imply that those operations have happened.

Minimum acceptance:
- `konoha` launches one conversation.
- pasted multiline mission is one turn;
- Codex creates the mission-specific graph;
- Hokage validates rather than replaces the plan;
- Claude/Ollama/Codex invocations are persisted as evidence with model and usage;
- specialized families are enforced;
- missing statutes stop execution;
- plan-level read-only approval;
- instruction changes remain proposals;
- private source scanning is opt-in and local.

## Known limitations

- `run_technical_plan` is registered and provider-routed, but has no
  orchestrator implementation yet; it fails closed rather than executing.
- `fallback` is represented in the v4 plan contract, but this is not
  automatic provider/family failover - no runtime code selects an
  alternate provider or family on its behalf.
- Model/planner output remains proposal/evidence only, subject to
  deterministic validation and explicit human approval.
